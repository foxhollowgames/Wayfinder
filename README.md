# Wayfinder

Wayfinder is a set of map-first study guides to the Bible, the Book of Mormon, and the Doctrine and Covenants.

**Live site:** <https://wayfinder.josephnewelldesign.com>

This repository is the starting point. The code lives in the repositories below. Each one deploys on its own to a folder of the live site.

## Repositories

| Part | Live path | Repository |
| --- | --- | --- |
| Home page (hub) | `/` | [foxhollowgames.github.io](https://github.com/foxhollowgames/foxhollowgames.github.io) |
| Bible | `/bible/` | [bible](https://github.com/foxhollowgames/bible) |
| Book of Mormon | `/book-of-mormon/` | [book-of-mormon](https://github.com/foxhollowgames/book-of-mormon) |
| Doctrine and Covenants | `/doctrine-and-covenants/` | [doctrine-and-covenants](https://github.com/foxhollowgames/doctrine-and-covenants) |


## Contribute

1. Pick the repository for the part you want to change.
2. Fork it and make a branch.
3. Follow that repository's README to run it on your computer.
4. Open a pull request against `main`.

To add a new volume, open an issue here first so we can agree on the name and path.
